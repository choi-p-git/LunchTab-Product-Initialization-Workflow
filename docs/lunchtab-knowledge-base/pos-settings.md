The POS settings view allows administrators to conﬁgure various aspects of each Point of Sale outlet. Note that the settings view is only available to users with a supervisory or administrative role. For further details on user roles, see the User Roles article. Value Description Sales Business Type By default, the POS will display products and pages for all sales business types within the school. Selecting a speciﬁc business type will restrict the POS to only processing sales for that business. Enable Receipt Printing Allows receipts to be printed to an attached receipt printer from the transaction history view. Auto Print Receipts If enabled, a receipt will automatically be printed to an attached receipt printer whenever a sale is processed. Hide Consumer Balances Optionally hides the family account balance for the loaded consumer in the checkout view. Restrict Transaction History To This POS The transaction history view shows transactions across all registered vending outlets by default. Enabling this will restrict to only displaying transactions from the current outlet. Return To Home On Checkout If enabled, the POS will return to the home navigation screen instead of remaining on the currently selected page of products. Value Description Allow Cashier Barcode Login Barcode login for cashiers is disabled by default due to lower security than the other supported login methods. Barcode login for cashiers can be enabled here. Allow Consumer Keypad Login Allows the identiﬁcation of consumers at the POS through an attached keypad. Enable Consumer Queue If enabled, credentials presented for a consumer at the POS while another consumer is loaded will be queued for processing. The next consumer will be loaded on completion of the current checkout and a maximum of one user may be queued at any time. Show Login Barcode On Consumer Panel By default, the barcode value used for login is not displayed within the app. Enabling this setting will display the barcode value beneath the consumer's name while they are loaded into the checkout view. Prevent Parent Login The loading of parents as consumers during the checkout process is disabled by default. Changing this value will include parents in consumer search and allow identiﬁcation via peripheral devices. Require Conﬁrmation On Cashier Logout Displays a conﬁrmation modal before a cashier is logged out. Value Description Default Payment Method Determines the payment method that will be used when pressing the main Pay button on the checkout view. Allow Cash Account Charges Enables the cash account charge functionality in the consumer panel. See Consumer Management for further details. Payment Alerts

Value Description Enable Sound Eﬀects Controls whether audible eﬀects will be played. Alert When Inactive Users Are Loaded Users are generally expected to be in Active account status when making purchases and an alert is shown for inactive users during consumer load. Alert When User Has Product Restrictions Controls whether an alert will be shown detailing any applicable product restrictions for the loaded consumer. Alert When User Has Spending Restrictions Controls whether an alert will be shown detailing any applicable spending limits for the loaded consumer. Alert When User Has Subscriptions Controls whether an alert will be shown detailing any active subscriptions for the loaded consumer. Alert When An Unrecognized Barcode Is Scanned If enabled, an alert will be shown detailing the value of any barcode that was not resolved to a consumer or product when it is scanned. Value Description Enable Idle Screen Controls whether the cashier will be automatically logged out and the idle screen displayed after the conﬁgured delay. Idle Delay The number of seconds before a vending outlet will switch to the idle screen. Idle Screen Message An optional message to display on the idle screen. Value Description Enable Order Collection Controls whether the POS will allows the collection of orders. If disabled, orders will not be shown or collectable on the POS. Idle Orders

Value Description Automatically Add Orders To Basket If enabled, any orders pending collection for the day will be automatically added to the basket when a consumer is loaded. If not enabled and the POS supports order collection, a summary of the consumer's orders will be shown and they may be added to the basket individually. Value Description Enable Cash Drawer Enables the cash drawer trigger and cash ﬂoat monitoring features for this POS. See the Cash Float for further details on this functionality. Value Description Check For Update The Lunchtab POS application will apply any required updates automatically.
