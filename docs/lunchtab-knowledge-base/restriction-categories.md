Restriction categories are used to prevent the accidental purchase of unsuitable prod- ucts by individuals or groups of users through the use of product restrictions. The categories may be used to apply restrictions to individuals (e.g. for products that contain allergens) or to user groups (e.g. for age restricted products that are unsuitable for members of student classiﬁcations). Restriction categories are managed in the Restriction Categories view. To add a restriction category, select Add Restriction Category from the actions menu. Value Description Name A name for the category. Description An optional description of the category. Color An optional color to use where an instance of this category tag is displayed against products. Display Sequence Optionally speciﬁes the order in which categories will be displayed in the UI. Is User Manageable If enabled, consumers will be able to modify restrictions based on this category for their family members. Otherwise restrictions relating to this category may only be managed by administrators. Restriction Categories
