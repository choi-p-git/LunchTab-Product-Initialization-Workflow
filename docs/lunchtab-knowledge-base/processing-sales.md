Sales are processed through the Checkout view of the POS application. This view allows cashiers to manage the current basket, add items, and complete transactions. A sale generally starts by loading a consumer by scanning their credentials with a pe- ripheral device, or searching for them. For further details on loading and managing consumers, see the Consumer Management article. Once a consumer is loaded, a user can locate products using the product navigation surface. The navigation surface is divided into curated pages of products, along with pages for any published menus for the day. Initially, the navigation surface will display the home page, which lists each navigable page of products and menu items. Products can be located by opening each page from the grid or by using the search function at the top-right to locate products by name or code. On opening a page, the available products will be displayed. Navigation Processing Sales

To return to the home page, press the home button at the top-left of the navigation sur- face. The POS application also supports barcode scanning of products, which will automati- cally add the product to the basket if the barcode is recognized. For further details on supported barcode scanners, see the Supported Devices article. Adding product items to the basket is as simple as pressing the product tile in the navi- gation surface or search dialog. Where there are multiple versions or sizes of a product, the user will be prompted to select the desired version before adding it to the basket. The basket will update to include the selected item, and the quantity can be increased with further presses of the product tile. Similarly, pressing the item in the basket will re- duce the quantity of the item. If an attempt is made to add a restricted product for the current consumer, an override of the restriction will be required to add the item to the basket. Once all items are added to the basket, the transaction can be completed by pressing the large Pay button at the bottom of the screen. This will process the sale using the default conﬁgured payment method for the POS, which is typically the family account balance. Alternative payment methods can be selected using the button next to the default pay button. In the case of a cash payment, a dialog will be presented to enter the amount of cash tendered, and the change due will be displayed. If the current consumer has a spending limit applied, their remaining eligible expendi- ture will be displayed above the basket total. If the basket total exceeds either the daily or weekly this limit, an override will be required to complete the transaction. Only cashiers with a supervisory or administrative role will be able to override these re- strictions. For further details on user roles, see the User Roles article.
