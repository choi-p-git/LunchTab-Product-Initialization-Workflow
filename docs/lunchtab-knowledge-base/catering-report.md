## Page 1

The Catering report helps streamline daily orders preparation by detailing each order, highlighting any allergies or dietary restrictions, and enabling easy printing of order lists and labels. The view can be accessed by expanding the sales business type in the sidebar and se- lecting Catering. Selecting a day or week will bring up an overview of that period's menu orders, broken down by each menu item. The view defaults to showing orders from all users but can be ﬁltered by Classiﬁcation, Group, Classroom, Campus or Boarding Type. Where menu items are being provided by external vendors, a vendor ﬁlter can also be applied to show only orders for a speciﬁc vendor. Pressing the View button next to a menu item or the All Items row will open a list of all applicable conﬁrmed orders. Overview Catering Report

## Page 2

Where there are multiple menus, pressing the View All Orders button next to the date will present a consolidated list of all of the day's orders. Indicators on each item indicate whether the order has been paid, already collected, or if the recipient has any dietary restrictions or allergies. Pressing the Print button will open a dialog to print the orders in list format or as Avery labels. Pressing the Download CSV button will export the selected orders to a CSV ﬁle ready for import into other external software. Where a menu has been linked to a related subscription, the catering view will also show an indication of the expected number of orders from subscribers who have not yet placed an order for the day.
