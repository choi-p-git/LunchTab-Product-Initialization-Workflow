Product version types are used to represent the diﬀerent versions of a base product that can be made available for sale. For example, a meal product in a cafeteria will have a standard version and potentially variants that oﬀer diﬀering portion sizes with an associated diﬀerence in price. In the case of a store that sells clothing products, these version types can represent the available sizes of the product. The product version types view can be accessed by expanding the sales business type in the sidebar and selecting Product Version Types. To add a new product version type, select Add Product Version Type from the actions menu. Value Description Name A name for the product version type. Description An optional description of the product version type. Consumer Group Preferences Deﬁnes the consumer groups that may be automatically assigned this version when purchasing. See Consumer Group Preferences for further details. Consumer group preferences allow you to deﬁne which consumer groups will automati- cally receive a speciﬁc product version when ordering menu items online or making purchases at the point of sale. If the user is a member of a group that has been assigned a preference to a product version, that version will be automatically selected instead of the standard version. When a user falls within multiple groups that have had a preference assigned, the pref- erences are assessed in priority order. Consumer Group Preferences Preference Priority Product Version Types
