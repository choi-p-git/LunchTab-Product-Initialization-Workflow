As well as standard email and password login, Lunchtab provides integration with a number of identity providers. This allows users to log in using their existing credentials from these providers. Identity providers can be conﬁgured in the Identity Providers page. To enable Google login, simply check the box in the Google panel and Save Changes. A Google button will now appear on the login screen and users will be able to log in us- ing their Google account where it matches the email address assigned to their Lunchtab user. To enable Veracross SSO login, you will need to provide some conﬁguration details. For further information on setting up Veracross SSO for your school, please refer to the Veracross documentation. Once you have added the Veracross conﬁguration details, the UI will display a Redirect URL. Please copy this value and add it to your Veracross SSO conﬁguration. Optionally provide a JPG or PNG image (recommended: 400x100px) to customize the button that will be displayed on the login page. To enable users to log in using Blackbaud SSO, simply check the box and Save Changes.
