The transaction history view allows cashiers to review the most recent transactions pro- cessed by Point of Sale outlets. By default, the view will show all transactions across all outlets but can be restricted to only the current outlet (see POS Settings). Using the search bar, transactions can be ﬁltered by consumer name. Selecting a transaction group from the list will display all transactions generated by the basket checkout. If the Enable Receipt Printing setting is enabled in the POS Settings, a receipt can be printed for the transaction group. For further details on supported receipt printing devices, see the Supported Devices ar- ticle. A refund action is available for each transaction in the group. If the transaction was paid from a family account, the refund will automatically return the paid amount to the account balance. If the transaction was paid with any other payment method, the amount paid will need to be manually returned to the customer via that payment method.. Receipt Printing Refunds Transaction History
