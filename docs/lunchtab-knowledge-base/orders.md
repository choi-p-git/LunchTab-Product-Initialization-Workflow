Orders are created whenever a user purchases a product through the web portal. Orders are associated with a sales business type and are used to track the status of a purchase through to collection by the recipient. The orders view can be accessed by expanding the sales business type in the sidebar and selecting Orders. Orders move through a series of statuses as they proceed from initial checkout on the web portal to collection at the point of sale. Status Description Conﬁrmed The order has been placed by a user but has not yet been collected at the point of sale. Payment may have been taken depending on the order payment point conﬁgured for the sales business type. Collected The order has been collected by the user at the point of sale and all required payment has been settled. Cancelled The order has been cancelled and any amount paid was not returned. Refunded The order was been cancelled and any amount paid was returned. Orders can be either cancelled or refunded depending on the status of the order. Cancellation can only be performed on orders that have not yet been collected, while refunds can be performed on orders in any state. Refunding orders will return the payment to the family account that payments were taken from, while cancelling orders will not return any payment. To perform cancellation of a single order, select the item in the orders view to open the Order Status Cancellation / Refunds Orders

Orders are generally marked as collected automatically when the user collects the or- der at the point of sale. However, in some cases it may be necessary to manually mark an order as collected through the web portal if collection did not occur at a vending outlet. To mark a single order as collected, select the item in the orders view to open the order details and use the Mark Collected button. Multiple orders can also be marked as collected simultaneously using bulk actions. To apply a bulk action to a group of orders, either select the individual items using the checkboxes next to their names in the view, or use the view ﬁlters to narrow down the desired selection. Then select Apply Bulk Action from the actions menu. Choose to either apply the action to the Selected Orders in the table, the Current Page of results, or All Results in scope of the currently applied ﬁlters. Select to either Mark Collected, Cancel or Refund the chosen orders. It is possible for an administrator to place a menu order on behalf of a user. This can be useful in situations where a user may have missed the deadline for order amendments, or is otherwise unable to place an order themselves. To place an order on behalf of a user, select Create Menu Orders from the actions menu. Select the user and date the order is for, and the available items for each menu on the day will be displayed.
