Spending restrictions can be used to constrain the expenditure of users on a daily or weekly basis, and limit the amount of overdraft available to a user. Restrictions for user groups are managed in the Spending Restrictions view. There are ﬁve spending restriction rules that can be applied to a user or group. Type Description Daily Spending Limit The maximum amount a user can spend on a daily basis (excluding any expenditure on exempt items). Weekly Spending Limit The maximum amount a user can spend on a weekly basis (excluding any expenditure on exempt items). Overdraft Limit (Excluding Exempt Items) The minimum balance a user's account will be allowed to reach when making purchases. Any items that are considered exempt from spending limits will be ignored from the calculation at time of purchase. Total Overdraft Limit The absolute minimum balance that a user's account will be allowed to reach when making purchases. Product category exemptions are ignored and this is considered a hard limit. Allowed Spending Hours Limits the hours of business that a user is able to make purchases with their account balance as the POS. This will not prevent checkout if the basket only contains pre-paid orders or items that are exempt / fully discounted. To add a new spending restriction for a group, select Add Spending Restriction from the actions menu. Value Description Restriction Rules Adding Restrictions For User Groups Spending Restrictions

Purchases of products within these categories will not be considered as contributing to the Daily / Weekly Spending Limit rules and will be ignored during assessment of the Overdraft Limit (Excluding Exempt Items) rule at time of purchase. Users will also be allowed to make purchases of these items when outside any conﬁg- ured Allowed Spending Hours time range. See the documentation for Product Categories for further details on marking categories as exempt from these restrictions.
