## Page 1

The Vending Outlets page in the admin portal lists all vending outlets currently regis- tered with the service. Selecting a vending outlet from the list will open the details view, which displays the outlet's current status and allows access to a number of remote functions. Remote functions are available from the Actions menu in the top right corner of the de- tails view. Function Description Revoke / Reinstate Access Revoking access will log out any current cashier from the outlet and it will prevent any further login or usage until access is reinstated. Remote Wipe / Delete The vending outlet will remove all of its local data and be unregistered from the service. Remote Functions Vending Outlet Administration

Function Description Unregister The registration state of the outlet will be cleared, allowing the device to be registered again under a diﬀerent name or the identity to be reused by registering another physical machine with the same name. Log In The current user on the web portal will be logged in as the cashier on the POS. This action is only available while the outlet is in an online status. Log Out Any currently logged in cashier on the POS will be logged out. This action is only available while the outlet is in an online status. Restart The Lunchtab application on the vending outlet will be restarted. This action is only available while the outlet is in an online status. Data Refresh The outlet will perform a full re-sync of all data from the Lunchtab service. If the outlet is not currently online, a sync will occur the next time it connects. Reboot The machine running the Lunchtab application will reboot. Note that the POS application will not automatically re-launch when Windows is restarted. Copyright © 2026 Lunchtab Inc.
