Product sales versions are the individual variations of a base product that can be sold. Each sales version can have its own price, barcode, inventory control settings, and more. Sales versions are generally created and managed within the context of their parent base product, for details of their conﬁguration see the Base Products documentation. To allow for easier management of sales versions across multiple base products, the product sales versions view oﬀers a number of bulk actions. The product sales versions view can be accessed by expanding the sales business type in the sidebar and selecting Product Sales Versions. To apply a bulk action to a group of sales versions, either select the individual items us- ing the checkboxes next to their names in the view, or use the view ﬁlters to narrow down the desired selection. Then select Apply Bulk Action from the actions menu. Choose to either apply the action to the Selected Users in the table, the Current Page of results, or All Results in scope of the currently applied ﬁlters. To update the price of a selection of sales versions, select the Update Price action. Note that if the result of any price adjustment would result in a negative price, the price will be set to zero. Adjustment Type Description Replacement Amount The price of all selected sales versions will be changed to the provided value. Fixed Adjustment The price of all selected sales versions will be increased (if positive) or reduced (if negative) by the amount provided. Bulk Actions Update Price Product Sales Versions

Adjustment Type Description Percentage Adjustment The price of all selected sales versions will be increased (if positive) or reduced (if negative) by the percentage provided. To update the low inventory threshold of a selection of sales versions, select the Update Low Inventory Threshold action. All selected sales versions will have their low inventory threshold set to the provided value, and if they are not currently under inventory control, it will be enabled.
