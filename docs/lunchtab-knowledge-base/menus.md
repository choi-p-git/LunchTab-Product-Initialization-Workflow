Menus are used to provide a weekly selection of meal options for users to either order in advance online, or purchase directly at the point of sale. Reminder notiﬁcations can be sent to users to prompt them to place their orders for the following week. Menus can also be associated with subscriptions to assist your catering team with an- ticipating further purchases on the day from subscribers who have not placed an order in advance. The menus conﬁguration view can be accessed by expanding the sales business type in the sidebar and selecting Menus. Menus typically represent a particular service or meal time, such as breakfast, lunch, or dinner. The items available for selection are deﬁned on a weekly basis using the Menu Builder. To create a new menu, select Add Menu from the actions menu of the menus view. Value Description Name The name of the menu. Display Sequence Optionally speciﬁes the order in which menus will be displayed in the UI. Notes Optional footnotes to display on the consumer upcoming menus browser and in-store promotional screens. Is Published Whether the menu is visible to users and accepting new orders. Is Orderable Whether the menu accepts advance orders online. Hide From POS By default, a page on the POS system is generated for each menu containing the day's items. Enabling this will remove the page for this menu from the POS. Creating Menus Menus

Allow Multiple Orders The default behavior allows a single order from each menu per day, enabling this will allow for multiple orders. Order Amendment Deadline Type The default behavior is to allow orders up to the start of the day that they are to be collected. This can be changed to require orders to be placed for the upcoming week or month in advance. Order Amendment Deadline Hours The number of hours before the start of the upcoming day/ week/month that orders must be placed. For example, a value 0 would indicate that orders must be placed by midnight at the start of the given period. This value can be negative, so an amendment type of Daily and a value of -9 would allow for orders to be placed until 9am on the day of collection. Related Subscriptions Associations with subscriptions can be used to provide additional information on the Catering Report. For example you may have a daily Lunch subscription associated with your Lunch menu. Subscribers of these associated subscriptions who have not placed an advance order will be listed on the catering report to assist with anticipating any additional meals that may be purchased on the day. Availability Menus are available to orders from all users by default. Adding selections to this ﬁeld will restrict ordering to only members of the deﬁned user groups. Once your menu has been created, you can deﬁne the items available for order on a weekly basis using the Menu Builder. Deﬁning Weekly Menu Items

## Page 3

The Menu Builder can be accessed by expanding the sales business type in the sidebar and selecting Menu Builder. Select the menu and week you wish to edit to open the menu builder canvas. Use the ﬁlters on the left column to locate the products you wish to add to the currently selected day. Add a product to the current day by either dragging it onto the canvas or by clicking the + button. Once items are added to the canvas you can drag to reorder them, which will deﬁne the order in which they will appear on the published menu. To remove an item from the week's menu, click the x button to remove it from the can- vas. Once you are happy with your selections, use the tabs at the top of the canvas to move on and ﬁll the next day. Adding / Removing / Ordering Items

If you have deﬁned an instance of the menu previously, it's easy to copy the items from a previous week or day to save time. To copy items, select either Copy Day Items or Copy Week Items from the actions menu, and select the day / week you wish to copy from. When copying a week, all items from the week will be copied to the corresponding days of the current week. When copying a day, only the items from the selected day will be copied to the currently selected day. All copied items will be created with any availability and any ordering limits conﬁgura- tions as they were deﬁned in the original week. By default, base products added to the menu will be added with all of their product versions available and with no limit on orders. The speciﬁc product version allocated to a user when ordering will follow any rules de- ﬁned as Consumer Group Preferences. These behaviors for a menu item can be amended by clicking the settings icon. Copying Previous Weeks / Days Item Conﬁguration
