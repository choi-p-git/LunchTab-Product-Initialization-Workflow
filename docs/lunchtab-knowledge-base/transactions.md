The Transactions view displays all ﬁnancial transactions that have been processed by the system. Selecting an entry in the transactions list opens the details of its parent transaction group. Receipts for a group of transactions can be generated by selecting the Receipt button at the top of the in the transaction details view. Transactions that are solely managed within Lunchtab will have a status of Complete, but those dependent on an external system (such as a payment gateway) may move through diﬀerent stages. Status Description Pending The transaction is in a proposed but unsubmitted state. This generally represents an account charge through a payment gateway where the user has not completed entry of payment details and conﬁrmed the payment. Processing The transaction is being processed by a payment gateway. The transaction will remain in this status until Lunchtab is notiﬁed by the 3rd party that it has been accepted or rejected. Complete The most common status and the initial state for transactions managed solely within Lunchtab. The transaction is conﬁrmed and any eﬀect on account balances and reporting will apply. Declined The attempted transaction was declined by a payment gateway or the funding bank. Abandoned The transaction was abandoned, either due to an administrator cancelling within the payment gateway or a consumer opting not to continue a transaction that was in a Pending state. Transactions can be exported to a CSV ﬁle by selecting Download CSV from the actions menu. The exported ﬁle will contain all transactions that match the current ﬁlter settings. Exports are restricted to a maximum of 250 thousand records. If the current query ex- ceeds this amount, apply some ﬁlters to reduce the size of the export. When family accounts have previously been managed in another system and moved to Lunchtab, it may be required to apply an initial amount to each account to reﬂect an existing balance. Select Import Initial Balances from the actions menu on the transactions view and Download CSV Template. The downloaded ﬁle will contain an entry for each family ac- count with a column for the initial balance amount. Add an amount for each account that needs an initial balance to be applied, and drop the edited ﬁle onto the upload area or select it using the ﬁle picker to begin the import process. Account credits and withdrawals can be created in bulk using the import balance ad- justments feature. Select Import Balance Adjustments from the actions menu and Download CSV Template. The downloaded ﬁle will contain an entry for an example family. Replace the example entry and ﬁll out the details for each family that requires a bal- ance adjustment. A row with a positive amount will create a new account charge trans- action to credit the family balance, and a negative amount will create an account with- drawal. Drop the edited ﬁle onto the upload area or select it using the ﬁle picker to begin the import process. This feature is intended for use as part of the initial setup process when moving accounts from a preexisting system to Lunchtab. Once the system is fully active and vending outlets have been registered, the feature will no longer be available. Any further adjustments to family account balances should be made using the Import Balance Adjustments feature or creating credit/withdrawal transactions manually. Sales that have been processed outside the Lunchtab website and POS outlets can be added in bulk using the import account sales feature. Select Import Account Sales from the actions menu and Download CSV Template. The downloaded ﬁle will contain an entry for an example family, customer and product. Replace the example entry and ﬁll out the details for each sale record that should be created. A new sale transaction will be created for each row and any relevant purchase fee will be deducted from the family account balance.
