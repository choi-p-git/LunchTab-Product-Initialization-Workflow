Vendors can be used to identify certain products as being provided by an external sup- plier, such as a restaurant or takeaway. Where a vendor is assigned to a product, its icon will be shown where the product ap- pears on ordering and menu views. Vendors can be used to ﬁlter products when working within the menu and POS builders, and to ﬁlter orders to ease collaboration with the vendor. Vendors are managed in the Vendors view. To add a vendor, select Add Vendor from the actions menu. Value Description Name A name for the vendor. Image An image / icon that will be used to represent the vendor when displaying associated products or menu items. Display Sequence Optionally speciﬁes the order in which vendors will be displayed in the UI. Vendors
