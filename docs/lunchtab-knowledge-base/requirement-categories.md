Requirement categories are used to indicate user requirements or preferences that a product complies with. Examples of requirement categories include dietary requirements, such as vegetarian or vegan, or compliance with religious laws such as halal or kosher. Requirement categories are shown to consumers against products that fulﬁll them in ordering and menu views. They are also displayed within the menu builder to indicate whether the menu has been prepared with options suitable for all dietary requirements. Requirement categories are managed in the Requirement Categories view. To add a requirement category, select Add Requirement Category from the actions menu. Value Description Name A name for the category. Description An optional description of the category. Color An optional color to use where an instance of this category tag is displayed against products. Display Sequence Optionally speciﬁes the order in which categories will be displayed in the UI. Is Required On Menu If enabled, warnings will be shown to an administrator within the menu builder when a menu does not contain any items that satisfy the requirement. Requirement Categories
