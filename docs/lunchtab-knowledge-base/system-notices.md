System notices can be used to display important information to users. They are dis- played at the top of the page and can be dismissed by the user. System notices comprise a title, which is displayed within the banner, and a main body which is displayed when the banner is pressed. The main body can contain HTML con- tent. Multiple notices can be conﬁgured at any time, and the banner will rotate between no- tices. To create a system notice, navigate to the System Notices page. Select Add System Notice from the actions menu to create a new notice. Give the notice a name, title, and content for the main body. Images and links can be added to the main body using the + button in the editor toolbar. Where multiple notices are conﬁgured, you can set the order in which they are dis- played. The notice with the lowest display sequence will be displayed ﬁrst. You can either immediately publish the notice, and it will be displayed immediately, or it may be left as a draft and published later. You can also disable a previously published notice by unpublishing it. Creating a System Notice System Notices
