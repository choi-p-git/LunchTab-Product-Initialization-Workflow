The Lunchtab Point of Sale application is installable on all systems running Windows 10 or 11 with x64 processor architecture. Minimum speciﬁcations: • 1024x768 Display Resolution • 4GB RAM It is recommended to use a touchscreen display for the best user experience, but it is not required. Lunchtab supports all USB NFC readers that are compatible with Windows and the PC/ SC standard. Most NFC readers should be compatible, but please reach out if you have questions re- garding a device you are intending to purchase. Lunchtab supports barcode scanners from Zebra Technologies . A full list of model numbers supported by the Windows driver can be found on the Zebra support page. Lunchtab supports Secugen ﬁngerprint readers for biometric authentication. Both of these installations must be performed by a Windows account with administra- tive privileges. The POS will print receipts to the standard 80mm roll width and is compatible with any printer with a Windows driver. The printer should be conﬁgured as the Windows default printer to allow the POS to print receipts without additional prompts. Lunchtab supports cash drawer trigger devices that can be connected to the POS ter- minal and trigger the cash drawer to open automatically when a cash payment is pro- cessed. Most triggers that connect to the POS via USB and signal the drawer via a virtual serial port should be compatible. Please reach out if you have questions or require assistance in selecting a compatible trigger device. Receipt Printers Cash Drawer Triggers
