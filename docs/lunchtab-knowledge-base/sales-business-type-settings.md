## Page 1

The settings view for each sales business type can be accessed by expanding its entry in the sidebar of the admin portal and selecting Settings. The available settings will diﬀer depending on the type of business, but all are de- scribed below. Value Description Name A name for the sales business type. Display Sequence Optionally speciﬁes the order in which the sales business types will be displayed in the UI. Published Whether the sales business type is visible to users in the customer portal. The sales business type can be hidden while it is initially being conﬁgured and published when ready to accept orders. Value Description Enable Online Ordering Whether customers can place orders through the website. If disabled, purchases may only be made at the point of sale. Hide Parents From Ordering If enabled, parents will not be displayed for selection on the ordering screens and they will only be able to place orders on behalf of their children. Order Payment Point Whether payment is required when orders are conﬁrmed online or paid during collection at the POS. Ordering Reminders For cafeteria business types, the day and time that ordering reminder notiﬁcations for menus will be sent to users. Note that the enabled state of ordering reminders is conﬁgured on a per- menu basis. General Ordering Sales Business Type Settings

For cafeteria business types, Lunchtab provides a page that can be used on promo- tional displays and will animate through the current menus. The URL for this page can be found on this settings tab. Value Description Hide Today Menus By default the menu promotional display will show the menu for the current week and more detail for the menu for the current day if available. Enabling this option will hide the menu for the current day and display only the weekly menu. Menu Week Switchover Deﬁnes the day and time that the promotional display will switch to displaying the following week's menus. Menu Promo Display Copyright © 2026 Lunchtab Inc.
