Product categories are used represent groups of related products. These relationships can then be used for ﬁltering and reporting, as well as forming the basis for subscrip- tion content and exclusions from spending restrictions. Your Lunchtab school has been created with an existing set of common product cate- gories, but it's easy to create and manage your own categories as needed. Product categories are managed in the Product Categories view. Product category types serve as a grouping for related categories. For example, your school will have been created with a default group for "Food and Drink" but you may have another for "Clothing" or other types of related categories. To add a new category type, select Add Product Category Type from the actions menu. Value Description Name A name for the product category type. Description An optional description of the category type. Display Sequence Optionally speciﬁes the order in which category types will be displayed in the UI. The child categories view can be accessed by pressing the Categories button next to the parent category type. To add a new category, select Add Product Category from the actions menu.
