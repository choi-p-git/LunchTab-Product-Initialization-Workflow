Base products represent each individual product that you sell. Each base product con- tains sales versions that can represent diﬀerent sizes, or other variations of the product. The base products view can be accessed by expanding the sales business type in the sidebar and selecting Base Products. To add a new base product, select Add Product from the actions menu. The ﬁrst step in creating a new base product is to conﬁgure the base product details. Value Description Image An image of the product. Name A name for the product. POS Name A shorter name for the base product to be displayed on the point of sale where space is restricted. Limited to 15 characters. Short Description A short description of the product that will be displayed on menus and product listings. It is recommended to limit this to a single sentence where possible to make best use of space in menus. Long Description An optional longer description that will be displayed when the user is viewing the detail of a single product and more space is available. Base Price This will form the price of the mandatory standard version of the product. Applicable only to Cafeteria sales business types. Adding A Base Product Base Product Conﬁguration Base Products

Value Description Barcodes A list of barcodes used to detect the product using a barcode scanner at the point of sale. Multiple barcodes can be entered with comma separation. Enable Inventory Control Whether inventory tracking and alerts are enabled for the product version. See Inventory Control for further details. Low Inventory Threshold If inventory control is enabled, the threshold at which low stock alerts will be sent for the product version. Is Orderable Deﬁnes whether the product version is available to order through the web portal. Applicable only to Store sales business types. Max Per Person Order Qty Optionally deﬁnes the maximum number of the version an individual user may order. Applicable only to Store sales business types. Valid To Date Optionally deﬁnes a date where the availability of the product version will be removed. Applicable only to Store sales business types. Restrict To User Groups By default product versions are available to all users. Adding a selection of user groups will restrict the ordering availability of the version to only those members. Product images can be imported in bulk by uploading a zip ﬁle containing images named to match the associated product handle. For example if the product's handle is beef-burger , a PNG image would be named beef-burger.png . Supported ﬁle formats for upload are png , jpg , gif , and webp . To ﬁnd the handle for a product, select the item in the products view to open the details view and the handle will be displayed below the name ﬁeld in the form. Select Import Product Images from the actions menu and drop the zip ﬁle onto the up- load area or select it using the ﬁle picker to begin the import process.
